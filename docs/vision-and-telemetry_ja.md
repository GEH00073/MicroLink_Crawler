# FPV・姿勢情報・赤色物体検出

[English](vision-and-telemetry.md) | 日本語

着脱可能なAtomS3R-CAMモジュールはチャンネル3でWi-Fiアクセスポイントを作成し、`/video`でMJPEGストリームを配信します。Core2はこのアクセスポイントに接続して映像を表示します。

カメラのファームウェアは、チャンネル3のESP-NOWでIMU情報を10 Hzで送信します。Core2はこの情報を用いて方位と傾きを表示します。カメラは赤色物体も検出し、検出時には緑色の検出枠と中心座標をモニターへ送ります。

可視遅延や長い停止を抑えるため、実装には次の処理があります。

- Core2はストリーミング中にWi-Fi省電力を無効化し、必要に応じて古いフレームを捨てて最新のデコード済みフレームを優先します。
- カメラは350 msのTCP送信タイムアウトを使用し、遅いクライアントがストリーミング処理を占有する時間を制限します。

設定とビルド対象は、[カメラファームウェアREADME](../Firmware/MC_AtomS3R_CAM_GC0308_gylo/README.md)および[Core2ファームウェアREADME](../Firmware/MC_Core2_cam_reciever_AP/README.md)を参照してください。
