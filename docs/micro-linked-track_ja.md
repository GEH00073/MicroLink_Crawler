# マイクロリンク式履帯

[English](micro-linked-track.md) | 日本語

マイクロリンク式履帯は、大型試作を段階的に縮小し、7 mm幅に到達するまで開発されました。一般的な0.4 mmノズルのFDMプリンターで造形した、機能する履帯システムであり、6 mm径の遊星ギヤードモーターで駆動します。

各履帯の中央ガイド溝と、スプロケット歯に合わせた開口部が連携します。これにより履帯の位置を保ち、駆動トルクを伝達して、外れや空転を抑えます。

本書は設計の補足であり、完全な製作手順ではありません。材料、印刷設定、寸法公差、組み立て順序は、使用する機器と部品に依存するため規定していません。

収録したSTL・F3Dデータは[3Dデータガイド](../3D_Printer_Data/README_ja.md)、確認済みの開発経緯は[開発の経緯](development-story_ja.md)を参照してください。
