# MicroLink Crawler 3D Data

English | [日本語](README_ja.md)

This directory contains the STL printing files and Fusion 360 F3D design files used for the MicroLink Crawler award project. STL files are intended for printing; F3D files are provided for design inspection or editing.

These files are structural reference data, not a complete fabrication manual. Printing and assembly can require adjustment for the printer, material, component tolerances, and tools in use.

| File | Format | Description |
| --- | --- | --- |
| `chassis.stl` / `chassis.f3d` | STL / F3D | Chassis design data |
| `hinge_s.stl` / `hinge_s.f3d` | STL / F3D | Hinge design data |
| `motor_bottom.stl` / `motor_bottom.f3d` | STL / F3D | Motor-bottom design data |
| `sprocket_9mm.stl` / `sprocket_9mm.f3d` | STL / F3D | Sprocket design data |
| `sprocket_9mm_2.stl` / `sprocket_9mm_2.f3d` | STL / F3D | Sprocket design data |

For the project context and track design notes, see the [root README](../README.md) and [micro linked tracks](../docs/micro-linked-track.md).
