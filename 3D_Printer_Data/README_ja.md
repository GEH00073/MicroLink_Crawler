# MicroLink Crawler 3Dデータ

[English](README.md) | 日本語

このディレクトリには、MicroLink Crawler受賞作品で使用したSTL造形データとFusion 360 F3D設計データを収録しています。STLは造形用、F3Dは設計確認・編集用のデータです。

これらは構造を確認するための参考データであり、完全な製作マニュアルではありません。プリンター、材料、部品の寸法公差、工具に応じて、造形や組み立ての調整が必要になる場合があります。

| ファイル | 形式 | 説明 |
| --- | --- | --- |
| `chassis.stl` / `chassis.f3d` | STL / F3D | シャーシ設計データ |
| `hinge_s.stl` / `hinge_s.f3d` | STL / F3D | ヒンジ設計データ |
| `motor_bottom.stl` / `motor_bottom.f3d` | STL / F3D | モーター下部の設計データ |
| `sprocket_9mm.stl` / `sprocket_9mm.f3d` | STL / F3D | スプロケット設計データ |
| `sprocket_9mm_2.stl` / `sprocket_9mm_2.f3d` | STL / F3D | スプロケット設計データ |

作品全体と履帯設計の説明は、[ルートREADME](../README_ja.md)および[マイクロリンク式履帯](../docs/micro-linked-track_ja.md)を参照してください。
